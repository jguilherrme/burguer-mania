# Prática de Design

[Github Pages](https://jguilherrme.github.io/burguer-mania)

## Atividade: Curricularização da Extensão

Projeto desenvolvido para a disciplina **Prática de Design**, com o objetivo de criar um cardápio digital para a empresa **Burguer Mania**, localizada em **Três Fronteiras - SP**.

O site foi desenvolvido pensando na organização das informações e na identidade visual da empresa. As cores utilizadas foram escolhidas com base no menu do Burguer Mania, principalmente **preto, laranja e subtons de preto**.

O site foi dividido em categorias para facilitar a navegação e a visualização dos produtos e trazer um pouco da história da empresa.

* Burguer Mania

## Identidade visual

A identidade visual foi baseada na logo na **Burguer Mania**, utilizando principalmente preto, laranja e e alguns subtons de preto para manter uma aparência consistente com a marca.
